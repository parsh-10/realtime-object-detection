# 🎯 Real-Time Object Detection with YOLOv8 + COCO

Fine-tuned YOLOv8s on the COCO128 dataset for real-time detection of 80 object classes.

## 📊 Results
| Metric | Score |
|--------|-------|
| mAP@50 | 92.1% |
| mAP@50-95 | 77.6% |
| Precision | 94.0% |
| Recall | 85.3% |

## 🚀 Demo
[Live Demo on Gradio](https://8e3695ecfb5973f68b.gradio.live)

## 📦 Dataset
COCO128 — subset of the COCO dataset (80 classes, 128 images)

## 🛠️ Tech Stack
- YOLOv8s (Ultralytics)
- PyTorch
- Google Colab (T4 GPU)
- Gradio

## ▶️ Run it yourself
```bash
pip install ultralytics gradio
```
